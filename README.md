# Dopamine RootHide книга — snapshot ветки

Эта ветка содержит текущий snapshot русскоязычной технической книги
«Разработка патчей и твиков для iOS 26.0–26.0.1 на A13: практическое руководство по Dopamine RootHide».

Книга — не часть исходного кода Dopamine. Она создавалась автоматически в cloud-сессии Claude Code
по заказу владельца репозитория для сохранения результатов работы над документацией.

## Структура
- `00-verification.md` — верификация целевой среды
- `00-outline.md`, `00-extended-plan.md`, `00-vol3-plan.md` — планы томов
- `part1/..part7/` — семь частей основной книги
- `appendix/` — приложения A–D
- `deep-dive/` — глубокие погружения
- `cookbook/` — рецепты
- `cheatsheets/` — шпаргалки
- `ios26-changes/` — дельта iOS 26
- `advanced/` — продвинутые темы
- `cases/` — case-studies с полным кодом
- `daemons/` — разбор системных демонов
- `framework-atlas/` — атлас фреймворков
- `re-walkthroughs/` — reverse-engineering walkthroughs

История ветки `3.x`, `claude/serene-knuth-h5qs09` и остальных не затронута — эта ветка orphan.
