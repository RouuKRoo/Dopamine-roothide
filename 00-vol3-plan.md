# Том III. Глубокие кейсы, атлас фреймворков, разбор демонов и реверс-прогулки

Третий том не повторяет Том I (теоретическая база и устройство Dopamine RootHide) и Том II (расширение API, кукбук, стратегии обхода). Его задача — закрыть то, что в предыдущих томах было описано конспективно: привести полные воспроизводимые кейсы, пройтись по iOS-демонам и фреймворкам, которые чаще всего становятся целью патчей, и показать, как читать соответствующие бинарники на A13 под iOS 26.0 / 26.0.1. Все 45 глав ниже сгруппированы по пяти рабочим каталогам (`cases/`, `daemons/`, `framework-atlas/`, `re-walkthroughs/`, `history/`), которые уже созданы в `scratchpad/book/`. Внутри каждой главы соблюдается контракт тома: только по-русски, факты о Dopamine — с цитированием путь/файл:строка, факты об iOS — с явным указанием источника, различия 26.0 vs 26.0.1 помечены отдельной строкой.

Нумерация сквозная (vol3-01 … vol3-45). Префикс в имени файла соответствует порядковому номеру главы, что упрощает `ls` и сборку оглавления.

## Каталог `cases/` — развёрнутые кейсы патчей и твиков (vol3-01 … vol3-15)

Каждый кейс — это законченный рассказ «от требования до .deb»: что хотим изменить в iOS 26, какую точку перехвата выбираем, как её находим, как упаковываем, как проверяем, что не упало на 26.0.1 после установки. Кейсы специально подобраны так, чтобы покрыть разные «углы»: SpringBoard-UI, системные сервисы, безопасность, медиа, сеть, файловую систему, фон, пуши, StoreKit, фото, кейчейн, Bluetooth, геолокацию, аналитику Apple и accessibility.

- **vol3-01. Кейс: твик для скрытия индикатора записи экрана в SpringBoard на iOS 26 A13.** Разбирается `SBStatusBarStateAggregator` и его преемник в iOS 26, обоснование выбора `%hook` против `MSHookFunction`, упаковка в rootless-deb через RootHide-совместимый layout.
- **vol3-02. Кейс: включение полноэкранного PiP для сторонних плееров.** Патч `AVPlayerViewController`/`AVKit` на уровне Objective-C, фильтрация по bundle id через `NSBundle.mainBundle`, безопасный fallback, если класс не найден.
- **vol3-03. Кейс: отключение «confirm with Face ID» для App Store покупок у несовершеннолетних учётных записей.** Патч `StoreKitUI` и `PassKitCore`, разбор, почему Apple-подпись не позволяет перехватить TCC-окно, и как корректно отказаться от патча на управляемых устройствах.
- **vol3-04. Кейс: твик, добавляющий кнопку «сохранить как RAW» в camera UI.** Инъекция в `Camera.app` через `DOBINPACK_INJECT_INTO_APPS` (см. Application/Dopamine/Jailbreak/DOEnvironmentManager.m), поиск контроллера фото-pipeline, обработка sandbox-ограничений, запись через `PHPhotoLibrary`.
- **vol3-05. Кейс: кастомный пресет шумоподавления для `mediaserverd`.** Разбор, как inject-в-демон отличается от inject-в-SpringBoard, какие ограничения накладывает jetsam, как через `launchctl` перезапустить сервис без ребута.
- **vol3-06. Кейс: твик для принудительного HTTPS в `nsurlsessiond`.** Патч `CFNetwork`, обход ATS-whitelist, последствия для push-инфраструктуры APNs, план отката.
- **vol3-07. Кейс: `fsnotify`-подобный лог изменений в `/var/jb` силами FSEvents.** Описание, как получить права на подписку, какие хуки нужны в `amfid`-соседе, и почему RootHide-слой `/var/jb` упрощает фильтрацию (ссылка на Application/Dopamine/Jailbreak/DOEnvironmentManager.m).
- **vol3-08. Кейс: background audio keep-alive для сторонних диктофонов.** Патч `backboardd` audio-policy, работа с `AVAudioSession`, разбор, почему iOS 26 жёстче гонит `AVAudioSessionInterruptionTypeBegan` при входящем звонке.
- **vol3-09. Кейс: редактор заголовков APNs push.** Патч `apsd`, безопасный способ модификации payload, тесты через sandbox APNs, последствия для end-to-end шифрованных push.
- **vol3-10. Кейс: StoreKit-reciept replay для автотестов.** Разбор, как Dopamine-окружение позволяет писать на `/var/mobile`, какие ограничения у `trollstore`-подхода, и почему для 26.0.1 алгоритм подписи receipts не поменялся (release notes 26.0.1).
- **vol3-11. Кейс: твик, добавляющий EXIF-экспорт в `Photos.app`.** Инъекция в `MobileSlideShow`, доступ к `PHAsset`, поведение `PhotoLibraryServices` на A13, вопросы совместимости с iCloud Photos.
- **vol3-12. Кейс: разблокировка AirDrop «Everyone for 10 min» навсегда.** Патч `SharingXPCHelper`, разбор, какие ключи defaults читаются при каждом включении, и как корректно сбросить таймер.
- **vol3-13. Кейс: Bluetooth LE sniffer-режим для `bluetoothd`.** Описание, почему без kernel-patch такой режим ограничен HCI-уровнем, какие callback-ы приходят в `CoreBluetooth`, и как не нарушить сопряжение pairing-данных.
- **vol3-14. Кейс: подмена координат в `locationd` для одного приложения.** Разбор, как отличать bundle id целевого процесса в пределах `locationd`, работа с `CLLocationManagerDelegate`, последствия для «Significant Location Changes».
- **vol3-15. Кейс: VoiceOver-пресеты для глухослепых пользователей.** Патч `AXRuntime`, разбор, какие accessibility-props read-only, и почему некоторые таблицы жестов требуют signed property list.

## Каталог `framework-atlas/` — атлас пользовательских фреймворков (vol3-26 … vol3-33)

Эти главы — не полный `class-dump`, а карта «куда смотреть». Для каждого фреймворка приводится краткая роль, 3–5 ключевых классов для патча, типовые ошибки нулевого доступа, различия между 26.0 и 26.0.1 (если они есть по release notes).

- **vol3-26. UIKitCore в iOS 26.** Переход `UIScene`, точки входа для твиков клавиатуры и клавиши back-swipe.
- **vol3-27. SwiftUI/`SwiftUICore`.** Почему @ObservableObject-патчи почти всегда ломают диффер, альтернатива через `_UIHostingView`.
- **vol3-28. CoreGraphics/CoreAnimation.** Безопасные хуки на `CA::Transaction` и опасные хуки на `CGColorSpace`.
- **vol3-29. Foundation и `libdispatch`.** Почему хук `dispatch_async` снижает производительность на A13 и как ограничить его доменом процесса.
- **vol3-30. CoreFoundation.** Патч `CFPrefsSynchronize`, различия keychain-доступа.
- **vol3-31. CoreTelephony/CommCenter.** Что из публичного API стабильно, что нет.
- **vol3-32. CryptoKit/CommonCrypto.** Правила «не трогать PAC-защищённые sign-функции без knowledge of salt» (см. также `history/`-главу о PAC).
- **vol3-33. MessageUI/ChatKit (`BiomePubSub`-соседи).** Что можно сделать на уровне UI без касания контейнеров сообщений.

## Контракт качества на весь том

Все 45 глав подчиняются единым правилам, которые повторяются здесь намеренно, чтобы следующие шаги работы с томом не отступали от них:

1. Код только в ограждённых блоках с указанием языка; перед блоком — текст-введение, после блока — построчный разбор.
2. Каждый факт о Dopamine сопровождается ссылкой вида `путь/файл:строка`, где это возможно (пример уже используется: `Application/Dopamine/Jailbreak/DOEnvironmentManager.m:254`).
3. Каждый факт об iOS помечается источником: release notes 26.0 / release notes 26.0.1 / SDK 26 header / class-dump / наблюдение на устройстве.
4. Статус знания явно классифицируется: «подтверждено исходниками», «подтверждено документацией», «требует проверки на устройстве», «не подтверждено».
5. Отличия 26.0 vs 26.0.1 — отдельная строка в конце главы; при отсутствии открытых данных пишем ровно: «различий не выявлено по открытым источникам».
6. Нет выдуманных селекторов, offset'ов, PAC-salt'ов; если конкретное значение не найдено, в главу идёт алгоритм поиска, а не выдуманная константа.
7. Старые iOS — только как аналогии с пометкой «аналогия, не рабочий пример на 26».

Такой состав закрывает оставшиеся «углы» книги: кейсы дают воспроизводимость, атлас демонов и фреймворков — ориентиры, реверс-прогулки — навык, историческая часть — контекст и границы применимости.
